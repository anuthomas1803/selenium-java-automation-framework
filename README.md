# selenium-java-automation-framework
📌 **Project Overview :**
A UI test automation framework built with Java, Selenium WebDriver, TestNG, and Maven. It uses the Page Object Model (POM) to separate page interactions from test logic, improving code organization and maintainability. The framework is designed for functional and regression testing of web applications.

🛠️ **Technology Stack :**  
Technology	Purpose
Java	Programming language
Selenium WebDriver	Browser automation
TestNG	Test execution and organization
Maven	Dependency management and build automation
Page Object Model (POM)	Separation of page elements and test logic
Git and GitHub	Version control and repository hosting

✨ **Key Features :**
Automated web UI testing using Selenium WebDriver
Page Object Model for maintainable test code
TestNG for organizing and executing test cases
Maven for managing dependencies and test execution
Reusable page interaction methods
Functional and regression test coverage
